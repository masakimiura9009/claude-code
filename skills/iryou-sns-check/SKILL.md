# 医療SNS 投稿前チェック（Ver.1.1）

発信者は糖尿病・内分泌・肥満症を専門とする医師。発信の目的は、正しい医療情報を届けることと、信頼を積み上げること。このスキルの役目は「公開してから困る」ものを公開前に止めることであって、原稿を無難で中身のないものに薄めることではない。正しい教育的内容まで削ると、発信する意味がなくなる。指摘は根拠のあるものに絞り、修正案は先生の言い回しと熱量をできるだけ残す。

本チェックは法的助言ではない。グレーな判断が残る場合は、その旨と相談先（クリニック所在地の保健所・都道府県の医療広告/薬務担当窓口、弁護士）を示す。

## 手順

### 1. 前提を読み取る

原稿から次を判断する。わからないものは推定し、「推定」と明記して先に進む（質問で止めない）。ただし「PR案件（企業から対価あり）か」だけは結論を大きく変えるので、原稿から判断できなければ確認事項として最後に挙げる。

- 媒体：YouTube（台本／タイトル／サムネ／概要欄／固定コメント）、note、X、Threads、Substack、その他
- 種類：一般向け疾患教育／クリニック告知・集患／自由診療の案内／PR・アフィリエイト／症例紹介／個別相談への返信
- 特定性：氏名・クリニック名・所在地・予約リンクが原稿かプロフィールにあるか

### 2. 「広告」に当たるかを判定する

ここが判定の土台になる。広告に当たると制限が一気に厳しくなるため、最初に結論と理由を書く。

- **医療法（医療広告ガイドライン）**：①誘引性（受診を促す意図）と②特定性（医師名・医療機関名が特定できる）の両方があれば広告。「当院で」「予約はプロフから」は両方を満たしやすい。純粋な疾患教育で受診先へ誘導しないものは該当しにくい。
- **薬機法**：①顧客を誘引する意図、②特定の医薬品等の名称が明らか、③一般人が認知できる、の3要件。医療用医薬品の商品名＋効果の強調＋受診導線がそろうと該当しやすい。
- 広告に当たらなくても、虚偽・誇大な表現は薬機法66条（「何人も」が対象）の問題になり、信頼も損なう。「広告ではないから何を書いてもよい」とはならない。

### 3. 7つの観点で点検する

各観点の詳細な根拠は references/ にある。該当しそうな観点のファイルだけ読めばよい。

| 観点 | 主な中身 | 参照 |
|---|---|---|
| A 医療広告GL | 虚偽・比較優良・誇大、体験談、ビフォーアフター、品位、限定解除、自由診療・未承認薬の必須記載 | references/iryou-koukoku.md |
| B 薬機法・適正広告基準 | 医療用医薬品の一般向け広告、承認外の効能（適応外）、効果保証、医師の推薦、サプリの医薬品的効能 | references/yakkihou.md |
| C 景表法・利益相反 | ステマ規制（PR表記）、アフィリエイト、製薬企業との利益相反の開示 | references/yakkihou.md |
| D 守秘義務・個人情報 | 症例の特定可能性、同意、画像への写り込み | references/privacy-ethics.md |
| E 個別診療 | DM・リプライでの具体的な診断・処方指示（医師法20条） | references/privacy-ethics.md |
| F 科学的正確性 | 数値の出典、平均と個人差、相対・絶対リスク、適応・保険要件の正確さ | 下記「科学的正確性」 |
| G 媒体特性・炎上 | 切り取り、文字数で注意書きが落ちる、サムネ・タイトルの誇大、他者批判 | references/platform.md |

**NG表現の一次スキャン**：Pythonが使えるなら、まず機械的に拾う（見落とし防止。最終判断は文脈で行う）。

```bash
python scripts/ng_scan.py 原稿.txt      # または標準入力: echo "本文" | python scripts/ng_scan.py
```

使えないときは references/ng_patterns.tsv を読み、同じ観点で目視する。スキャンの一致は「候補」にすぎない。例えば「必ず」は「必ず主治医に相談を」なら問題ない。文脈で判定する。

原稿の中の矛盾も点検する（例：「先月来院」と「3か月で改善」が両立しない、前後で数値が違う）。視聴者はこうした矛盾に気づき、内容全体の信頼が落ちる。

### 4. 修正版を自己点検する

修正版を書いたら、出す前に読み直す。指摘した表現（「治る」「痩せる」など）が修正版やタイトル案に残っていないか、新たな問題を持ち込んでいないかを確かめる（ng_scan.py が使えるなら修正版にもかける）。指摘したのに修正版で同じことをしていると、チェック全体の信用がなくなる。

### 5. 出力する

下の「出力形式」に従う。「根拠」欄には、法令・ガイドライン・添付文書など、先生が自分で確認できる一次情報の名前を書く。このスキル内部のファイル名（references/〜.md、ng_patterns.tsv）は先生には意味がないので書かない。

## 判定基準

- 🔴 **要修正（このままでは公開不可）**：法令・ガイドライン違反の可能性が高い、または患者が特定されうる、または医学的に誤り。
- 🟡 **修正推奨**：違反とまでは言いにくいが、誤解・切り取り・炎上の余地がある。グレーゾーン。
- 🟢 **問題なし**：指摘がないか、軽微な提案のみ。

総合判定は、最も重い指摘に合わせる。

## 糖尿病・肥満領域で特に多い落とし穴

経験上ひっかかりやすいもの。理由を理解したうえで、文脈で判断する。

- **医療用医薬品の商品名＋効果＋受診導線**（「ゼップバウンドで-12kg、当院で処方可」）：医療用医薬品は一般の人に向けて広告しない決まりがある。疾患教育として触れるなら、一般名（セマグルチド、チルゼパチド）を使い、効果を強調せず、受診導線と同じ投稿に混ぜない。
- **適応外の効能（美容・痩身目的のGLP-1、糖尿病薬で痩せる等）**：承認されていない効能の広告は薬機法68条で禁止。関連学会も適応外使用に注意を呼びかけている。サクセンダ（リラグルチド3.0mg）は国内で肥満症の承認がない点も要注意。
- **体験談・ビフォーアフター・「〇kg痩せた患者さん」**：医療広告では治療効果に関する体験談は禁止。ビフォーアフターは、治療内容・費用・主なリスクと副作用を詳しく併記しない限り不可。
- **効果の保証・安全性の断定**（「必ず」「誰でも」「副作用なし」「リバウンドしない」「打つだけで」）：臨床試験は平均値で、個人差がある。中止後の体重の再増加も報告されている。食事療法・運動療法が前提であることも落ちやすい。
- **保険適用の説明が不正確**：肥満症治療薬の保険適用には、BMI・合併する健康障害・食事運動療法の期間・処方施設などの要件がある。要件があることを書き、細かい数値は最新の添付文書や最適使用推進ガイドラインに当たる（記憶で書かない）。
- **「糖尿病が治る」**：一般に「寛解」と表現するのが正確。
- **症例の特定可能性**：年代・性別・地域・職業・受診時期・まれな経過の組み合わせで、本人や知人には分かってしまう。
- **医師の推薦・医師監修サプリ**：対象が医薬品か食品かで根拠が変わる。医薬品なら、医師が保証したと誤解させる記事は薬機法66条2項、医薬関係者の推薦は医薬品等適正広告基準の問題。健康食品・サプリは、まず健康増進法（虚偽誇大表示）と景品表示法（優良誤認）。ただし「血糖値を下げる」のような医薬品的効能をうたうと、無承認医薬品として薬機法の対象になる。どちらでも、「専門医が患者に勧める」という形そのものが、受診中の患者の自己判断を招くので🔴寄りに扱い、修正版でもその形を残さない。
- **一般的な受診のすすめは問題ない**：「気になる方は医療機関に相談を」「主治医に相談を」は、むしろ望ましい一文。特定の医療機関への誘導（「当院へ」「予約はこちら」）とは区別し、指摘しない。
- **比較・最上級**（「日本一」「No.1」「最先端」「唯一」）、**キャンペーン・割引の強調**：比較優良・誇大・品位の問題。
- **PR表記なし・利益相反の未開示**：企業から対価を受けた投稿はPR表記が必要（ステマ規制）。製薬企業と金銭関係がある製品を語るときは開示が望ましい。

## 科学的正確性（観点F）

- 数値（減量率、HbA1c低下、リスク低下）は試験名・対象・期間・平均であることを確認する。出典があいまいなら「出典確認」の指摘を出す。pubmed プラグインが使えるなら原著で照合してよい。記憶だけで数値を断定しない。
- 平均値を個人の結果のように書いていないか（「15%痩せる」→「試験の平均で約15%の減少、個人差あり」）。
- 相対リスク低下だけを示して絶対差を省いていないか。相関を因果のように書いていないか。
- 適応・用法・保険要件・副作用が添付文書と矛盾しないか。
- 修正版で数値を書き換えるときは、確かなものだけにする。不確かなら数値を削るか、「要出典確認」と残す。

## 出力形式

次の構成で出力する。

```
## 投稿前チェック結果

**総合判定**：🔴 要修正 ／ 🟡 修正推奨 ／ 🟢 問題なし（いずれか）
**ひとことで**：（最も大事な指摘を1〜2文で）

**前提の読み取り**
- 媒体：…　種類：…　特定性：…（推定なら「推定」）
- 医療広告に当たるか：該当／非該当／グレー（理由1行）
- 薬機法上の広告に当たるか：該当／非該当／グレー（理由1行）

### 指摘一覧
| # | 判定 | 該当箇所（原文を引用） | 観点 | 根拠 | なぜ問題か | 修正案 |
|---|---|---|---|---|---|---|
（重い順。良い点を指摘として並べない）

### 修正版（そのまま投稿できる形）
（媒体の形式に合わせる。Xは1投稿140字（全角）を目安に、スレッドなら各投稿に番号。
 YouTubeはタイトル／サムネ文言／概要欄を分けて出す。
 先生の文体・語尾・熱量を残し、直したのは指摘箇所だけにする）

### 公開前に人が確認すること
- [ ] （原稿ごとに必要なものだけ。例：数値の出典、患者の書面同意、PR案件か、利益相反、プロフィールの予約リンク）

※本チェックは法的助言ではありません。判断に迷う場合は、所在地の保健所・都道府県の医療広告／薬務担当窓口、または弁護士にご相談ください。
```

原稿に問題がない（🟢）ときは、指摘一覧を「なし」とし、修正版の代わりに「このまま公開して問題ありません」と書く。磨き上げの提案があれば1〜2点だけ添える。

画像（サムネ、スライド、検査結果のスクショ等）が添付されたら、画像内の文字と写り込み（患者ID、氏名、電子カルテの画面、他の患者）も点検対象にする。
