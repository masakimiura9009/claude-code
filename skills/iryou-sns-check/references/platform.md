# 観点G：媒体ごとの注意点と炎上リスク

共通の原則：**1つの投稿・1枚のサムネだけが切り取られて拡散されても誤解されないか**を考える。注意書きや前提が別の投稿・本文の後半にあると、拡散されるときに落ちる。

## プロフィール（全媒体共通）

- クリニック名、所在地、予約リンクがあると、すべての投稿に「特定性」が加わる。そのうえで受診を促す投稿をすると、医療広告と判断されやすい。
- 「〇〇専門医」「No.1」などの肩書は、広告できる資格か、比較優良に当たらないかを確認する。

## X

- 1投稿は全角140字が目安（有料プランは長文可）。字数を削ると、副作用・個人差・適応の限定といった注意書きが真っ先に落ちる。注意書きは1投稿目に入れる。
- スレッドは1投稿目だけが拡散されやすい。1投稿目だけで誤解されないようにする。
- 引用リポストで切り取られることを前提にする。皮肉や強い言い切りは、文脈を外れると誤解される。
- ハッシュタグ（#痩せ薬 #ダイエット #GLP1ダイエット）は、適応外の用途や痩身目的と結びつきやすく、誘引性も強める。

## Threads

- Xと同様に切り取られやすい。500字まで書けるが、冒頭が表示の中心になる。
- Instagramと連携していると、フォロワー層（一般の人、若年層）が広がる。痩身目的の需要と結びつきやすいことを意識する。

## YouTube

- 点検の対象：タイトル、サムネの文言、台本、概要欄、固定コメント、チャプター名。
- **サムネとタイトルは最も誇大になりやすい**（「たった1本で-10kg」「医者が教える最強の〜」）。本編で丁寧に説明していても、サムネだけが独り歩きする。サムネ単体で🟡以上の指摘を出す。
- ショート動画は前提の説明が入らない。注意書きを画面内のテキストに入れる。
- YouTubeには独自の「医療に関する誤った情報」ポリシーがあり、保健当局の見解に反する内容は削除の対象になりうる。
- 概要欄のPR表記・アフィリエイト表記は、「もっと見る」を開かなくても見える最初の数行に入れる。

## note

- 有料記事でも、有料部分を含めて点検の対象になる。
- タイトルと見出し画像が、Xなどでシェアされたときの「顔」になる。誇大になっていないか確認する。
- 自院への誘導リンクを記事末尾に置くと、記事全体が広告的に読まれる。

## Substack

- ニュースレターはメールで届く。長文の記事（Post）は下書きで確認できるが、**Notesは即時公開される**。Notesの文面は特に慎重に。
- 長文の記事は前提を書けるが、件名（Subject）とプレビューテキストが切り取られる単位になる。

## 炎上しやすいパターン（法令違反でなくても🟡）

- 「〇〇は意味がない」「〇〇を食べると死ぬ」などの断定と恐怖訴求
- 体型・容姿に関する価値判断（「太っている人は〜」）。肥満は疾患であり、スティグマを避ける言葉を選ぶ（「肥満の人」より「肥満症のある人」など、日本肥満学会などのスティグマに関する提言の考え方）
- 他の医師・インフルエンサーへの名指しの反論
- 患者や一般の人の行動を揶揄する投稿
- 製品名を出した批判（企業からの反応やCOIの疑いを招く）
