# 観点A：医療広告ガイドライン（医療法）

根拠：医療法 第6条の5〜第6条の8、医療法施行規則、「医業若しくは歯科医業又は病院若しくは診療所に関する広告等に関する指針（医療広告ガイドライン）」と、そのQ&A。2018年6月の改正医療法の施行により、医療機関のWebサイトも規制の対象になった。SNS、YouTube、note、メルマガも同じ考え方で判断する。

細部はガイドラインとQ&Aの改訂で変わりうる。条文番号や細かい要件を断定する前に、最新版を確認するよう添える。

## 1. 広告に当たるか

次の両方を満たすと「広告」になる。

- **誘引性**：患者の受診などを誘う意図がある
- **特定性**：医業を行う者の氏名、または病院・診療所の名称が特定できる

例：
- 「当院では〇〇の治療ができます。予約はプロフのリンクから」→ 両方を満たす。広告。
- クリニック名と予約リンクがプロフィールにあり、投稿が自院の治療を勧める内容 → 広告と判断されやすい。
- 「GLP-1受容体作動薬とは何か」の一般的な解説で、特定の受診先に誘導しない → 該当しにくい。ただし虚偽や誇大な表現は別の法令の問題になる。

「医師個人のアカウントだから広告ではない」とは限らない。実態（誘引性と特定性）で判断される。

## 2. 禁止される広告（内容に関係なく不可）

| 種類 | 例 | ポイント |
|---|---|---|
| 虚偽広告 | 「絶対安全」「100%痩せる」 | 医学上ありえない、事実と異なる |
| 比較優良広告 | 「日本一」「No.1」「地域最高」「他院より効果的」 | 他の医療機関と比べて優れていると示す |
| 誇大広告 | 「最先端」「画期的」「著名人も通院」、根拠の薄い「〇〇専門」 | 事実を不当に誇張し、誤認させる |
| 体験談 | 「患者さんから『10kg痩せた！』との声」、口コミの転載・引用 | 患者の主観や伝聞にもとづく、治療内容・効果に関する体験談は不可 |
| ビフォーアフター | 治療前後の写真・体重グラフ | 通常必要な治療内容・費用・主なリスクと副作用を詳しく併記しない限り不可 |
| 公序良俗に反する | わいせつ・残虐な表現 | |
| 品位を損ねる | 「今だけ半額」「キャンペーン」「来院者にプレゼント」 | 費用の強調、提供物による誘引 |
| 他の法令・指針で禁止 | 薬機法・景表法の違反表現 | |

専門医の表示は、広告できる専門性資格に当たるかを確認する。

## 3. 広告できる事項と「限定解除」

医療広告で書ける内容は、法令で定めた事項に限られる。ただし次の要件をすべて満たせば、それ以外の事項も書ける（限定解除）。

1. 患者が自ら求めて入手する情報を表示するWebサイトなどである
2. 問い合わせ先を記載している
3. 自由診療については、通常必要な治療の内容と費用を記載している
4. 自由診療については、主なリスクと副作用を記載している

※3と4は自由診療の場合の要件。

SNS広告、バナー、タイムラインに流れてくる投稿は「患者が自ら求めて入手する情報」に当たりにくく、限定解除が認められない可能性が高い。判断がつかなければ🟡とし、Q&Aの確認を促す。

## 4. 自由診療・未承認医薬品の場合に必要な記載

自由診療で、未承認の医薬品や承認外の用途（適応外）の医薬品を使う治療を案内する場合は、次の記載が求められる。

- 未承認医薬品等であること（または承認外の用途であること）
- 入手経路
- 国内で承認されている同様の医薬品の有無
- 諸外国での安全性などの情報
- 医薬品副作用被害救済制度の対象外となりうること

例：自費のGLP-1ダイエット、海外から入手したサクセンダの案内などは、これらがなければ🔴。そもそも適応外の効能を広告すること自体が薬機法68条の問題になる（yakkihou.md参照）。

## 5. 違反した場合

都道府県などによる報告命令・立入検査、中止命令・是正命令の対象になり、虚偽広告などには罰則がある。厚生労働省の「医療機関ネットパトロール」で通報・監視も行われている。
