# 観点B：薬機法・医薬品等適正広告基準／観点C：景品表示法・利益相反

条文番号・通知名は代表的なもの。細部は改訂で変わりうるため、断定が必要な場面では最新版を確認するよう添える。

## B-1. 薬機法上の「広告」

次の3要件をすべて満たすと広告に当たる。

1. 顧客を誘引する（購入・使用・受診を促す）意図が明らか
2. 特定の医薬品等の商品名が明らか
3. 一般人が認知できる状態にある

SNS・YouTube・noteは3を満たす。1と2の組み合わせ（商品名＋効果の強調＋受診や購入への導線）が判断の焦点になる。

## B-2. 主な規制

| 条文・基準 | 内容 | SNSでの典型例 |
|---|---|---|
| 薬機法66条1項 | 何人も、医薬品等の名称・効能効果などについて虚偽・誇大な広告をしてはならない | 「副作用なし」「必ず痩せる」 |
| 薬機法66条2項 | 医師などが効能効果を保証したと誤解されるおそれのある記事も虚偽・誇大広告に当たる | 「医師の私が保証します」「医師推奨」 |
| 薬機法67条 | がんなど特定の疾病用の医薬品は、一般向けの広告が制限される | （この領域ではまれ） |
| 薬機法68条 | 承認前の医薬品、または承認されていない効能効果の広告は禁止 | 美容・痩身目的のGLP-1、「糖尿病薬で痩せる」、国内未承認薬の宣伝 |
| 医薬品等適正広告基準 | 医療用医薬品は、医薬関係者以外の一般人に向けた広告を行わない | 一般向けにウゴービ・マンジャロ等を宣伝する投稿 |
| 同基準 | 効能効果や安全性を保証する表現、最大級の表現の禁止 | 「確実」「安全」「最高の効果」 |
| 同基準 | 医薬関係者などが推薦・指導・選用しているという広告の禁止 | 「医師が選んだ」「専門医推奨のサプリ」 |

### 実務上の線引き

- **疾患教育として医薬品に触れるのは可能**：一般名（セマグルチド、チルゼパチド、メトホルミン等）を使い、承認された効能・用法の範囲で、効果を強調せず、受診・購入の導線と切り離す。副作用と適応の限定も併記する。
- **避けたいのは「商品名＋効果＋導線」の組み合わせ**：「ゼップバウンドで-12kg！当院で処方中」は典型的な🔴。
- 適応外の用途で、効果をうたう表現は避ける（関連学会も、GLP-1受容体作動薬の適応外使用に注意を呼びかけている）。

## B-3. 健康食品・サプリメント

- 医薬品でないものが「血糖値を下げる」「糖尿病に効く」「脂肪を燃やす」など医薬品的な効能をうたうと、無承認医薬品の広告とみなされうる（いわゆる46通知の考え方）。
- 健康増進法（虚偽誇大広告の禁止）も関係する。
- 機能性表示食品・特定保健用食品は、届出・許可を受けた表示の範囲内に限る（例：「食後の血糖値の上昇を穏やかにする」は届出の範囲なら可。「血糖値を下げる」は不可）。
- 医師の推薦は、66条2項と適正広告基準の両方にかかる。医師が「推薦する」形のアフィリエイトはリスクが高い。

## C-1. ステマ規制（景品表示法）

- 2023年10月1日から、「一般消費者が事業者の表示であることを判別することが困難である表示」（ステルスマーケティング）が景品表示法の不当表示として規制されている。
- 企業から対価（金銭、商品の無償提供、謝礼など）を受けて投稿する場合は、「広告」「PR」「プロモーション」などと、一目で分かる位置にはっきり表示する。ハッシュタグの羅列に埋もれたり、概要欄の最下部に置いたりするだけでは不十分とみなされうる。
- 規制の対象は広告主（事業者）だが、投稿する医師の信頼の問題として🟡以上で指摘する。
- アフィリエイトリンクも、その旨を明示する。

## C-2. 利益相反（COI）

- 製薬企業や医療機器企業から講演料・顧問料などを受けている場合、その企業の製品について語るときは、利益相反の開示が望ましい（日本医学会のCOI管理ガイドラインの考え方。製薬企業から医師への支払いは業界団体の透明性ガイドラインにより公開されている）。
- 法的義務とは言い切れないが、開示がないと後から発覚したときの信頼の損失が大きい。🟡として「該当すれば開示を」と確認事項に入れる。
