# 病名管理システム

保険査定対応の病名管理ソフトウェアです。医事課からの依頼に基づき、検査項目や処方薬から必要な病名を素早く作成・管理できます。

## 主な機能

### 1. 病名管理
- 病名の登録・編集・削除（CRUD機能）
- 病名の検索・フィルタリング
- ICD-10コード、カテゴリ、症状、治療方法などの詳細情報管理

### 2. 病名提案機能
- 検査項目や処方薬を選択すると、保険査定上必要な病名を自動提案
- 医事課からの「この患者さんの病名を入れてください」という依頼に素早く対応
- 採血検査や処方内容に基づいた病名の自動推奨

### 3. 検査・処方との紐付け
- 病名と検査項目の関連付け
- 病名と処方薬の関連付け
- 逆引き検索（検査/処方から関連病名を表示）

### 4. 参照機能
- 検査項目一覧と関連病名の表示
- 処方薬一覧と関連病名の表示

## 技術スタック

- **バックエンド**: Python 3, Flask, SQLite
- **フロントエンド**: HTML5, CSS3, JavaScript (Vanilla)
- **データベース**: SQLite

## 使用方法

### 病名の管理

1. **病名の追加**
   - 「+ 新規病名追加」ボタンをクリック
   - 必要な情報を入力（病名は必須）
   - 「保存」をクリック

2. **病名の検索**
   - 検索ボックスに病名、カナ、説明を入力
   - カテゴリでフィルタリング可能
   - 「検索」ボタンをクリック

3. **病名の編集・削除**
   - 各病名カードの「編集」ボタンで編集
   - 「削除」ボタンで削除（確認ダイアログが表示されます）

### 病名の提案（メイン機能）

1. 「病名提案」タブをクリック
2. 患者さんに実施する検査項目をチェック
3. 処方する薬剤をチェック
4. 「病名を提案」ボタンをクリック
5. 保険査定上必要な病名が自動的に提案されます

**使用例:**
- 血糖値とHbA1cの検査を選択 → 「糖尿病」が提案される
- アムロジピンを処方 → 「高血圧症」が提案される
- LDLコレステロール検査 + スタチン系薬剤 → 「脂質異常症」が提案される

### 参照情報の確認

「検査・処方一覧」タブで以下を確認できます:
- 全検査項目と関連する病名
- 全処方薬と関連する病名

## データベース構造

- **diseases**: 病名マスター
- **tests**: 検査項目マスター
- **prescriptions**: 処方薬マスター
- **disease_tests**: 病名と検査の関連テーブル
- **disease_prescriptions**: 病名と処方の関連テーブル

## API エンドポイント

### 病名関連
- `GET /api/diseases` - 病名一覧取得
- `GET /api/diseases/<id>` - 病名詳細取得
- `POST /api/diseases` - 病名追加
- `PUT /api/diseases/<id>` - 病名更新
- `DELETE /api/diseases/<id>` - 病名削除
- `GET /api/categories` - カテゴリ一覧取得

### 検査・処方関連
- `GET /api/tests` - 検査項目一覧
- `GET /api/prescriptions` - 処方薬一覧
- `GET /api/diseases/<id>/tests` - 病名に関連する検査
- `GET /api/diseases/<id>/prescriptions` - 病名に関連する処方
- `GET /api/tests/<id>/diseases` - 検査に関連する病名
- `GET /api/prescriptions/<id>/diseases` - 処方に関連する病名

### 病名提案
- `POST /api/suggest-diseases` - 検査・処方から病名を提案

## サンプルデータ

初回起動時に以下のサンプルデータが自動的に登録されます:

**病名:**
- 糖尿病、高血圧症、インフルエンザ、気管支喘息、急性胃腸炎、脂質異常症、貧血

**検査項目:**
- 血糖値、HbA1c、総コレステロール、LDL、HDL、中性脂肪、赤血球数、ヘモグロビン、白血球数、CRP

**処方薬:**
- メトホルミン、アムロジピン、アトルバスタチン、オセルタミビル、フェロミア、レボフロキサシン
