# claude-code
claude code の調整作業

## カルテ作成ツール

音声データの内容を500文字以内に要約してカルテ形式で出力するツールです。

**厚生局の個別指導要件に対応:**
- 診療記録（約300文字）+ 指導内容（約200文字）の自動生成
- 在宅自己注射指導管理料、特定疾患療養管理料の算定要件を満たす指導記録を自動追記
- **指導内容はカルテ内容に応じて動的に生成**（糖尿病、腎機能、高血圧、インスリン等の状態に応じて最適化）

### 使用方法

#### Web版（推奨）

1. `karte_viewer.html` をブラウザで開く
2. テキストエリアに音声データの内容を入力
3. 「カルテ作成」ボタンをクリック
4. 生成されたカルテをクリックするとクリップボードにコピーされます

**特徴:**
- 美しいUI/UXデザイン
- ワンクリックでコピー
- リアルタイム文字数カウント
- ブラウザだけで動作（インストール不要）

#### コマンドライン版

1. 音声データの内容をテキストファイルに保存
2. 以下のコマンドを実行:

```bash
python karte_creator.py <テキストファイル>
```

または、標準入力から直接入力:

```bash
echo "診療内容..." | python karte_creator.py -
```

### 機能

- 音声データの内容を500文字以内に自動要約
- カルテ形式で整形して出力（診療記録 + 指導内容）
- 日付は自動的に今日の日付が設定されます
- 指導内容を自動追記（厚生局要件対応、カルテ内容に応じて動的生成）
  - 糖尿病管理: 血糖測定、食事療法、HbA1c管理、低血糖対応
  - インスリン治療: 自己注射手技、投与量調整、針廃棄方法、緊急時対応
  - 腎機能管理: 水分摂取、塩分制限、たんぱく質制限、透析予防
  - 高血圧管理: 血圧測定、減塩指導、ストレス管理
  - 一般的指導: 内服継続、生活習慣改善、禁煙・節酒、異常時対応
- クリックでクリップボードにコピー（Web版）
