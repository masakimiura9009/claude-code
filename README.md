# 肥満症チェックリスト

肥満症のリスクを簡単に評価できるウェブアプリケーションです。

## 機能

- **BMI計算**: 身長と体重からBMIを自動計算
- **包括的な評価**: 健康リスク要因、生活習慣、家族歴を考慮
- **リスク判定**: 低・中・高リスクの3段階で評価
- **個別推奨事項**: 各自の状況に応じた改善アドバイス

## 使い方

1. ブラウザで `index.html` を開く
2. 基本情報（身長、体重、年齢）を入力
3. 該当するチェック項目にチェックを入れる
4. 「診断結果を見る」ボタンをクリック

## 評価項目

### 📊 基本情報
- 身長・体重（BMI計算）
- 年齢

### 🏥 健康リスク要因
- 高血圧
- 糖尿病
- 脂質異常症
- 脂肪肝
- 睡眠時無呼吸症候群
- 関節痛

### 🍔 生活習慣
- 食生活（食べ過ぎ、夜食、外食、間食）
- 運動習慣
- 飲酒習慣

### 👨‍👩‍👧‍👦 家族歴
- 糖尿病
- 心疾患
- 肥満

## BMI判定基準

| BMI | 判定 |
|-----|------|
| 18.5未満 | 低体重 |
| 18.5〜25未満 | 普通体重 |
| 25〜30未満 | 肥満(1度) |
| 30〜35未満 | 肥満(2度) |
| 35以上 | 肥満(3度以上) |

## 注意事項

このチェックリストは健康管理の参考情報として提供されています。
正式な診断や治療については、必ず医療機関で専門医にご相談ください。
