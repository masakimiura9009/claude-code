# 肥満症診断チェックリスト

**看護師向け患者スクリーニングツール**

日本肥満学会の「肥満症診療ガイドライン」に基づいた、医療機関での患者スクリーニングのためのウェブアプリケーションです。

## 🎯 目的

肥満症外来への紹介が必要な患者を早期に発見し、適切な医療介入につなげるための看護師向けスクリーニングツールです。

## ✨ 主な機能

- **医学的に正確な診断基準**: 日本肥満学会のガイドラインに準拠
- **3ステップの簡単評価**: 基本情報 → 治療中疾患 → 健康障害
- **自動判定システム**: BMI + 合併症から肥満症リスクを評価
- **明確な受診推奨**: リスクレベルに応じた受診勧奨メッセージ
- **印刷機能**: カルテ保管・患者説明用に印刷可能
- **内臓脂肪評価**: 腹囲測定による内臓脂肪型肥満の判定

## 📋 使い方

### 1. 基本情報の入力
- 身長・体重（BMI自動計算）
- 腹囲（内臓脂肪型肥満の評価）
- 年齢・性別

### 2. 治療中疾患のチェック（A群）
以下のいずれか1つ以上該当で肥満症の可能性が高まります：
- 高血圧症（薬物治療中）
- 脂質異常症（薬物治療中）
- 2型糖尿病（薬物治療中）

### 3. 健康障害のチェック（B群）
肥満に関連する11種類の健康障害：
1. 耐糖能障害（2型糖尿病など）
2. 脂質異常症
3. 高血圧
4. 高尿酸血症・痛風
5. 冠動脈疾患（心筋梗塞など）
6. 脳梗塞・一過性脳虚血発作
7. 非アルコール性脂肪性肝疾患（NAFLD）
8. 月経異常・女性不妊
9. 睡眠時無呼吸症候群・肥満低換気症候群
10. 運動器疾患（変形性関節症など）
11. 肥満関連腎臓病

## 🩺 診断基準

### 肥満症と診断される条件

**肥満（BMI ≥ 25）** + 以下のいずれか：

1. **A群該当**: 治療中の疾患が1つ以上
2. **B群該当**:
   - BMI 27以上 + 健康障害が2つ以上
   - BMI 25以上 + 健康障害が1つ以上
3. **内臓脂肪型肥満**: 腹囲が基準値以上
   - 男性：85cm以上
   - 女性：90cm以上

### 判定結果

| 判定 | 条件 | 対応 |
|------|------|------|
| **高度肥満症の可能性が高い** | BMI ≥ 35 | 🔴 至急受診推奨 |
| **肥満症の可能性が高い** | BMI ≥ 25 + A群1つ以上<br>または BMI ≥ 27 + B群2つ以上 | 🔴 至急受診推奨 |
| **肥満症の可能性あり** | BMI ≥ 25 + B群1つ以上 | 🟠 受診推奨 |
| **内臓脂肪型肥満あり** | BMI ≥ 25 + 腹囲基準超過 | 🟠 受診推奨 |
| **肥満（経過観察）** | BMI ≥ 25のみ | 🟡 生活改善指導 |
| **可能性は低い** | BMI < 25 | ✅ 健康維持 |

## 💊 治療方針（参考情報）

### 基本治療
1. **食事療法**: バランスの良い食事、カロリー制限
2. **運動療法**: 有酸素運動（週5回、1日30分以上）
3. **行動療法**: 食事記録、体重測定、生活習慣改善

### 高度肥満症の場合（BMI ≥ 35）
- 薬物療法の検討
- 外科治療（肥満外科手術）の検討

### 減量目標
- 初期目標: 3〜6ヶ月で現体重の3〜5%減量
- 長期目標: BMI 25未満または内臓脂肪面積100cm²未満

## 🖨️ 印刷機能

「印刷」ボタンをクリックすると、以下の用途で使用できます：
- カルテへの添付
- 患者への説明資料
- 他科・他院への紹介状添付資料

## 📌 医療従事者への注意事項

### このツールの位置づけ
- **スクリーニングツール**: 肥満症の可能性を早期発見するための補助ツール
- **最終診断は医師が実施**: 詳細な検査と総合的判断が必要
- **受診勧奨の根拠資料**: 患者説明と受診動機づけに活用

### 追加検査が必要な場合
最終診断には以下の検査が推奨されます：
- **内臓脂肪面積測定**: 腹部CT検査（100cm²以上で内臓脂肪型肥満）
- **血液検査**: 血糖、HbA1c、脂質、肝機能、尿酸など
- **血圧測定**: 高血圧の評価
- **その他**: 必要に応じて睡眠検査、心機能検査など

### 免責事項
このチェックリストは医学的スクリーニングの補助ツールです。診断・治療は必ず医師の判断のもとで行ってください。

## 🚀 追加推奨事項

### 患者への説明で伝えるべきポイント
1. **肥満症は病気**: 単なる「太っている」状態ではなく、治療が必要な疾患
2. **早期介入の重要性**: 合併症予防のため早期治療が効果的
3. **治療の可能性**: 食事・運動療法で改善可能、必要に応じて薬物療法も
4. **継続的管理**: 減量後も継続的なフォローが重要

### 院内での活用方法
- 健康診断後のフォローアップ面談
- 外来初診時のスクリーニング
- 生活習慣病外来での評価
- 特定保健指導での活用
