# claude-code
claude code の調整作業

## カルテ作成ツール

音声データの内容を500文字以内に要約してカルテ形式で出力するツールです。

**厚生局の個別指導要件に対応:**
- 診療記録（約300文字）+ 指導内容（約200文字）の自動生成
- 在宅自己注射指導管理料、特定疾患療養管理料の算定要件を満たす指導記録を自動追記

### 使用方法

#### Web版（推奨）

1. `karte_viewer.html` をブラウザで開く
2. テキストエリアに音声データの内容を入力
3. 「カルテ作成」ボタンをクリック
4. 生成されたカルテをクリックするとクリップボードにコピーされます

**特徴:**
- 美しいUI/UXデザイン
- ワンクリックでコピー
- リアルタイム文字数カウント
- ブラウザだけで動作（インストール不要）

#### コマンドライン版

1. 音声データの内容をテキストファイルに保存
2. 以下のコマンドを実行:

```bash
python karte_creator.py <テキストファイル>
```

または、標準入力から直接入力:

```bash
echo "診療内容..." | python karte_creator.py -
```

### 機能

- 音声データの内容を500文字以内に自動要約
- カルテ形式で整形して出力（診療記録 + 指導内容）
- 日付は自動的に今日の日付が設定されます
- 指導内容を自動追記（厚生局要件対応）
  - 内服薬の継続指導
  - 食事・塩分制限指導
  - 水分摂取指導
  - 体重測定と異常時の受診基準
  - 生活習慣改善指導
  - 禁煙・節酒指導
  - 異常時の連絡指導
- クリックでクリップボードにコピー（Web版）
