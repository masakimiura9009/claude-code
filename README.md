# claude-code
claude code の調整作業

## カルテ作成ツール

音声データの内容を200文字以内に要約してカルテ形式で出力するツールです。

### 使用方法

1. 音声データの内容をテキストファイルに保存
2. 以下のコマンドを実行:

```bash
python karte_creator.py <テキストファイル>
```

または、標準入力から直接入力:

```bash
echo "診療内容..." | python karte_creator.py -
```

### 機能

- 音声データの内容を200文字以内に自動要約
- カルテ形式で整形して出力
- 日付は自動的に今日の日付が設定されます（2025年10月28日）
